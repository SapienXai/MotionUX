# Compose and tailor an app

Open **Build** and choose a starter. Under **Library**, select **Sections** to find a composition compatible with the project. Click the name for a live sample and **Insert** to add it. The outline exposes the section and each child block. Use the move, duplicate and remove controls in **Properties** to work with the selection by keyboard. Use **Patterns** or **Add page** for a whole-page pattern.

In **Design identity**, choose a preset and select **Preview preset** to try it on the canvas. **Apply preset** records it in the draft, where Undo and Redo can recover the earlier appearance. Density, typography and corners can be changed independently. The Studio's appearance menu controls the authoring shell. **Default theme** controls the authored app.

Select a section in **Outline** to open **Section layout** and **Responsive**. Pick a device in the canvas and check the actual frame width. **Editing size** identifies which values you are modifying. **Reset this override** removes the selected mobile or tablet override. **Focus canvas** gives the page more room on desktop. On small screens switch between Library, Canvas and Properties.

Select an Article library to edit its **Content items**. In Relay, **Task collection** lets you author the records used by both the queue and workload summary. Save publishes those authored records to the project revision. Completion and reopening in an installed app are browser-local and follow the saved-revision scope.

In a marketing project, **Media** can filter by current draft usage and show the pages that reference an image. Select an owned image under **Block image** to replace it and preview its fit and focal point. Enter alt text when the image communicates information. The regular media backup and protected deletion flow applies.

**Edit** shows the editable draft and **Interact** runs its actual controls. **Run** starts an isolated Next.js runtime for the saved revision using the existing macOS host. **Export** and **Export PWA** download independent Next.js source. After initial online setup, PWA export can use its saved offline pages and local interactions.
