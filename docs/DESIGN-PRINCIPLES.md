# Interaction design principles

Studio's first screen is a place to try motion. Typography and the catalog explain what each control does. The specimen has one primary action, a legible rest state and enough room for long Turkish labels.

- Use motion to connect the action to its result. Preserve an indicator or a point of origin when its identity carries across layouts.
- Follow a gesture as it happens. Settle from the release direction, allow cancellation, and keep an equivalent single activation for essential actions.
- Give control labels and focus the same care as timing. A focus ring, visible state, and readable outcome should survive theming and reduced motion.
- Distinguish a request from an outcome. Loading, tool approval, authorization and payment results come from the caller.
- Apply the product’s own typography, spacing, color and density through its adapter. Test long text at 320px before tuning the wide layout.
- Review visual craft and runtime performance separately. A visually smooth recording does not establish CPU, layout, or throughput under load.
