# MotionUX Studio V5 design reference

The supplied PNG measures 1280 × 853. The table uses its coordinates scaled to the requested 1536 × 1024 review frame. The original is preserved beside this document and kept out of the application build.

| Region | Target at 1536 × 1024 |
| --- | --- |
| Sidebar | x 0–270; logo around x 33, y 36; navigation y 121; categories y 391; project card x 16, y 777 |
| Toolbar | x 305, y 21; 45px search height; two 51px icon boxes at right |
| Hero | x 305, y 109; approximately 44px heavy Inter with tight tracking; supporting text y 169 |
| Gallery | x 290, y 236; two equal columns with 12–14px gap; rows near 240–252px |
| Card | 1px neutral border, ~18px radius, 10px inset, stage ~64% with lila fill and 14px radius |
| Card copy | 20–22px title, 14–15px description, quiet tags, 37px outline action aligned to the bottom |
| Key colors | Near-white canvas, dark ink, light lavender stage, coral active states, neutral borders |

The first six cards follow the reference order. Gallery-only titles and categories describe the preview composition. IDs, registry names, historical pins and providers come from the inventory. Button, card and gesture groupings are derived from a Studio category mapping. Secondary inventory categories are available under More categories. The media assets are original fixtures. The shell uses Inter Variable with the existing typography package. Tablet keeps horizontal stage/copy, while phones stack them and use a modal drawer.

Scope is limited to MotionUX Studio and compatible changes to its previews. The BookPlace and DineWallet adapters live under the Studio stage.
