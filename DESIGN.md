# MotionUX Studio V8

The live [DesignBookmark Motion catalog](https://designbookmark.com/motion) is the layout and interaction reference. MotionUX has a neutral sidebar and content panel, a compact heading, inline filters, and a preview-first catalog with one, two or three columns. The first row follows reference inventory order. Card actions lead to the live Playground, React usage and the pinned installer.

- Inter Variable, neutral surfaces and a high-contrast accent define the default theme. First visit follows the operating system and a visitor can persist an override. Shared recipe CSS also ships with the installed examples. BookPlace and DineWallet remain optional stage themes.
- Keep demo stages mounted near the viewport. A focused demo stays mounted until focus leaves. Controls remain reachable by keyboard and touch.
- Start from the live reference when evaluating the behavior of a component. Record the exact states observed and use independent implementation unless upstream redistribution rights are documented.
- The V5 target and measurements are historical. [V5 design spec](docs/design-reference/STUDIO-V5-DESIGN-SPEC.md)
