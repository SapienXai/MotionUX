# Changelog

## Unreleased · Studio V8

- Rebuilt the Gallery around live previews in a monochrome layout with system light and dark modes, direct Playground links and responsive filtering.
- Reworked the Plan Switch, Letter Limit and Pull Cord examples. Added geometry changes and motion controls for radial actions, inline menus, Morph Island, Rubber Dock and Siri Orb. Added touch tracking to Glass Lens and progressive drag resistance to Pull to Refresh.
- Published the shared theme with the installed presets and expanded the isolated React interaction suite to 41 recipe scenarios. [V8 acceptance report](docs/V8-ACCEPTANCE.md)

## Unreleased · Studio V7

- Shared the Gallery compositions with React consumers through five installable recipe families.
- Added fixed-clock motion comparison for the six featured presets.
- Improved deck release continuity and dock magnification. Added live jelly thumb elasticity and a Motion panel for supported controls.

## Studio V6 · candidate previews

- Install the six featured Studio compositions as separate presets with their public props, primitive sources, styles and MIT fixture assets.
- Edit real props in Playground, share a bounded configuration and copy generated React usage.
- Resolve installation pins against the same source files shown in Code. GitHub CI installs and compares the six Gallery presets in an isolated consumer.
- Require explicit caller state for the Loading Outcome. Add continuous Goo Menu lobes, shared-size Morph Island motion and configurable swipe and pull thresholds.

## Studio previews · unreleased

- MotionUX Studio runs the source-qualified catalog with 82 interactive references, copyable registry pins and examples, three theme previews, width and language controls, and reduced-motion comparison.
- Navigation, feedback, form, card, gesture, typography, assistant and media previews extend the GitHub registry.
- Registry CI builds the source, installs it into a clean consumer, and exercises desktop Chromium, mobile Chromium and iPhone-profile WebKit. Check the [verification ledger](docs/VERIFICATION.md) for coverage and open gates.
- Existing `v1.0.0` imports stay at the same paths. To evaluate a Studio item, install it alongside the v1 component, use a product adapter, and compare behavior before migrating any route.

## v1.0.0

The first stable release provides the scoped motion foundation, navigation dock, native disclosure and status pill with a GitHub shadcn registry. [Tagged release](https://github.com/SapienXai/MotionUX/tree/v1.0.0)
